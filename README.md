# Quiz Dataset Dashboard

An interactive Streamlit dashboard and a static Pandas-based dashboard for analyzing quiz datasets.  
This project helps visualize quiz data, track KPIs, and generate reports with charts and summaries.

---

## 📦 Installation

Install dependencies:
```bash
pip install -r requirements.txt
## Usage 

###Run interactive Dashboard

streamlit run notebooks/Data_interactive.py

##Run Static Dahboard

python notebook/Data.Visualization.py

##Features
Sidebar filters for category and level

KPIs: total questions, categories, true answer rate, top category

Visualizations: bar charts, pie charts, heatmaps

Report folder with saved visualizations

Static dashboard cleaned with Pandas
